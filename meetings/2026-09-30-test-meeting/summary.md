# Test Meeting – Product Announcement: Dots, Spaces, and Codex Updates

**Date:** 2026-09-30T05:46:00.0000000

## Overview
The meeting was a product announcement presentation led by Dulitha Lakshan. It introduced new AI features including 'Dots' (always-on AI agents), 'ChatGPT Spaces' (a collaborative workspace for users, teammates, and agents), and updates to Codex including Linux and mobile support. A demo was teased using a fictional music app called Blossom.

## Key Points
- Codex has been brought to Linux and to mobile phones, responding to user requests.
- Dots are described as remarkably capable, always-on AI agents that can handle complex and ambitious tasks, not just trivial ones like booking reservations.
- Dots are powered by 'Astra,' OpenAI's most aligned model, and include built-in protections, safeguards, and customizable instructions.
- Dots have their own computer and browser in the cloud, can write and test code, and can communicate via text message with updates.
- ChatGPT Spaces is a collaborative environment where users, teammates, and agents can work together on pages, track dependencies, and eventually build presentations.
- Spaces can be given specific standing instructions, such as monitoring a Slack channel and updating a page daily.
- A live demo was planned using a fictional music playlist app called Blossom, featuring a personal Dot named 'Dottie.'
- Presentation building inside Spaces is coming soon, enabling team collaboration with Dots.
